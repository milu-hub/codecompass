# CodeCompass 项目背景

## 一句话定位
输入一个公开 GitHub 仓库，自动生成项目地图、学习路线、AI 代码问答与理解测验，把优质开源项目变成可交互的教材。

## 产品目标
面向**多语言**代码理解与教学平台，不绑定单一语言。

## 核心痛点
- P1 不知道从哪开始读
- P2 看不懂模块关系
- P3 不知道核心流程
- P4 没人带、没人问
- P5 看完就忘

## 六个核心能力（长期愿景）
- F1 项目地图
- F2 学习路线
- F3 AI 代码问答
- F4 自动测验
- F5 笔记·进度·成就
- F6 可分享"领读页"

MVP 只做 F1 + F3 的最小垂直切片。

## 技术栈区分（关键）
**自身开发技术栈**（长期不变）：
- 后端：Java 21 + Spring Boot 4.x + Maven
- 前端：Vue3 + Vite + Pinia + Element Plus + Mermaid
- 缓存：内存缓存（MVP，单实例）；Redis 后置，作为多实例扩展选项
- AI：DeepSeek / 通义 / Kimi / OpenAI 兼容 API
- 部署：Docker Compose + 阿里云学生机 + Nginx

**支持的解析目标**（产品能力，面向多语言）：
- 产品目标：多语言
- MVP 首发：只实现 Java / Spring 解析器
- 后续：Python、Go、TypeScript 等按适配器扩展

## 定位原则
- AI 是"副驾驶 / 教练"，不是"替代者"
- 只分析公开仓库，尊重 license
- 不存储完整私有代码
- AI 回答引用具体行号，可跳转验证
- 人类专家在环，可纠错、可标注

## 成本
0～200 元/月起步。
成本控制四原则：缓存分析结果 · 只发相关片段 · 接口限流 · 异步任务。
